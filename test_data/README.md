## Running the example
1. Upload example_e.coli_ref.fasta as Reference, example_e.coli_query.fasta as Query
2. You can get the starting subsequence by copying the references preview and pasting as text
3. All other settings will auto-configure from the reference length
4. Expected runtime: ~3 minutes
5. Expected output: 6 mutated ORFs, 2 in/dels 4 points, 1 truncated protein, 2 silent mutations
